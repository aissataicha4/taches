# Smart Touch - قائمة مهامي

تطبيق مهام عربي بسيط باستخدام HTML وCSS وJavaScript، قابل للنشر على GitHub Pages ويعمل كتطبيق ويب تقدمي (PWA).

## تجربة سريعة على Windows
1. فك ضغط المجلد.
2. افتح `index.html` بالنقر المزدوج لتجربة الوظائف الأساسية.
3. للتثبيت على الهاتف والعمل دون اتصال، انشر المشروع على GitHub Pages (يتطلب HTTPS).

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً باسم `smart-touch-tasks`.
2. ارفع الملفات الأربعة الموجودة في هذا المجلد إلى جذر المستودع.
3. من Settings ثم Pages، اختر Deploy from a branch.
4. اختر `main` و`/(root)` ثم Save.
5. انتظر حتى يظهر رابط الموقع في صفحة Pages، وافتحه من هاتف Android عبر Chrome.
6. من قائمة Chrome اختر Install app أو Add to Home screen.

## ملاحظات
- المهام محفوظة محلياً في المتصفح على نفس الجهاز باستخدام localStorage.
- لا توجد قاعدة بيانات أو مزامنة بين الأجهزة في هذا الإصدار.
- لا ترفع معلومات شخصية أو حساسة إلى نسخة تجريبية عامة.
